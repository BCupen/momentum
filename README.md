# Momentum

Momentum is an early-stage study/focus interface centered on a "growing snowball" metaphor that reflects session progress.

## Current prototype includes

- Live start/end focus sessions.
- Animated snowball that grows with elapsed session time.
- Persisted completed sessions.
- Calendar heatmap and per-day session history.

## Getting started

```bash
npm install
npm run dev
```
